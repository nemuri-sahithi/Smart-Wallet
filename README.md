# 🎓 Smart Wallet

A student-focused personal finance management application built with Python and Streamlit.

## 📌 About the Project

Smart Wallet helps students manage their pocket money, track daily expenses, monitor monthly bills, set savings goals, and plan future purchases.

## ✨ Features

- 💰 Track wallet balance
- 💵 Add income
- 💸 Record daily expenses
- 🧾 Manage and pay monthly bills
- 🎯 Set savings goals
- ✅ Calculate safe-to-spend amount
- 📜 View transaction history
- 🚩 Flag high-value transactions
- 🔮 Dream Planner for savings-based purchase planning
- 📊 View basic spending information

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- HTML/CSS styling through Streamlit

## 🚀 How to Run

1. Clone this repository.
2. Install the required Python packages.
3. Run the Streamlit application.

pip install -r requirements.txt
